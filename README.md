# Cálculo del total de una compra

**Nombre del estudiante:** Tu Nombre

## Descripción

Este proyecto contiene un programa sencillo desarrollado en Python
que permite calcular el total de una compra.

La función `calcular_total()` recibe dos parámetros:

- `precio`: precio de un producto.
- `cantidad`: cantidad de productos que compra el cliente.

La función multiplica el precio por la cantidad y retorna el resultado.

## Ejemplo

Si el precio del producto es 10 y la cantidad es 3:

`10 * 3 = 30`

Por lo tanto, el total de la compra es 30.
